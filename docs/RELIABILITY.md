# 停止、网络恢复与本地目录

## 编码失败与审查失败的区别

编码没有提交时，消息、版本和审查数量都为零，测试尚未开始。旧版把读取超时、连接中断与 SSE 解析错误合并为一个提示，无法从旧报告还原准确底层类型。新记录使用 `stream_timeout`、`stream_transport`、`stream_incomplete`、`sse_format` 等分类；只有 401 / 403 才需要优先检查密钥或权限。

流式空闲读取默认 120 秒，可在网页网络设置调整为 1–300 秒。单次模型请求还有 600 秒总等待预算。自动兼容默认最多两次流式尝试，再尝试一次普通响应；恢复范围仅限当前尚未提交的节点。普通模式保留命名工具选择与本地 schema 校验，不把未完成参数当作代码交付。鉴权失败不使用节点重试。

服务返回普通 JSON、最后一个 SSE 事件没有空行时可以正确处理。响应缺少完成标志、返回非法 UTF-8 JSON 或超过容量限制时仍明确拒绝，不通过容错接纳截断代码。

## 停止与公开进度

网络 IO 使用最多八个后台工作线程与有界队列；共享状态、回调与检查点只在运行线程提交。运行线程以 100 ms 间隔检查停止令牌，连接建立后跟踪 TCP / TLS 套接字，停止时 shutdown 并关闭连接。等待响应头和中途静默不再阻塞停止。连接建立前的 DNS / 建连由后台线程退出或超时，调用方及时停止；连接和后台任务数量有界。

测试进程每 20 ms 检查停止令牌，停止后清理进程树。浏览器先发出服务端停止请求；超过两秒仍未结束会停止本地接收，并保留可重新打开的检查点。云端是否继续计算由服务商处理，关闭连接不等于保证云端计算立即结束。

页面显示公开行动计划、有效响应信号数、公开交付字符数、部分代码 / 测试与最终校验结果。内部 reasoning 内容和加密协议项不进入页面、草稿、状态或日志。没有收到公开代码时不会虚构代码完成进度。草稿属于未校验输出，不能作为通过证据。

## 目录、文件与测试输入

用户可选择本地目录或输入路径；本机目录注册表保存在应用的 `.agentcoder/workspaces.json`，刷新与重启可恢复。新运行的代码和检查点保存到所选目录的 `.agentcoder/runs/<id>/`。历史和恢复根据已经授权的目录查找，切换新目录不改变旧运行的位置。模型密钥仍保存在应用目录，不复制到所选目录。

新建文件只接受本目录的 `.py` 文件名和最多 64 KiB UTF-8 内容，使用排他创建防止覆盖；路径越界和系统保留名会拒绝。已有源码保持只读，原始文件不会自动写回。仍是单 Python 模块工作流，选择目录不代表扫描或改写整个项目。

纯 unittest 文件若从单个非标准库模块导入被测函数，会作为原始回归测试使用。例如 `from calculator import average`：测试逐字冻结，编码生成实现，运行目录与交付包同时提供 `solution.py` 和同内容的 `calculator.py`。标准库、应用包名和路径不能作为交付别名，以免遮蔽运行环境。模型提示明确区分实现输入与测试输入。

接口与格式参考 [OpenAI Docs：Function Calling](https://developers.openai.com/api/docs/guides/function-calling)、[Python socket shutdown / close](https://docs.python.org/3.13/library/socket.html#socket.socket.shutdown)、[Python HTTPResponse](https://docs.python.org/3.13/library/http.client.html#httpresponse-objects)。第三方服务的兼容性仍以实际验证为准。
