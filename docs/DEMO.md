# 一分钟演示

```powershell
python -m agentcoder serve
```

打开 http://127.0.0.1:8767，首次配置窗口选择“离线演示”。该演示清楚标为规则 Agent，不调用云端模型。

已录制实际浏览器操作的 [48 秒视频](assets/demo.mp4)（H.264 MP4，无配音）。

| 时间 | 展示 |
| --- | --- |
| 0–10 秒 | 介绍三类角色与任务，显示“编码 → 审查 → 修复”节点 |
| 10–25 秒 | 含缺陷样例开始运行，观察交接消息、测试失败、修复分支与复审 |
| 25–40 秒 | 展示原始与最终测试状态、带位置的四个问题、最新代码和冻结测试 |
| 40–50 秒 | 打开 Agent 消息，说明发送方、接收方与代码/测试哈希 |
| 50–58 秒 | 选择正确模块演示，观察审查直接通过、修复节点跳过，再下载报告 |

命令行也可运行 `python -m agentcoder demo` 或 `python -m agentcoder demo --scenario clean`。真实模式会根据当前模型耗时运行，教学录像使用可重复的离线样例。
