# 使用演示

运行 `python -m agentcoder serve`，打开 [本机网页](http://127.0.0.1:8767)。

1. 首次启动填写 API、模型和服务地址；也可选择明确标注的离线演示。
2. 选择工作目录，载入已有 Python 模块或新建代码文件。启动前查看代码来源、测试执行方式与修复预算。
3. 离线教学任务可展示“编码 → 审查 → 修复 → 复审”及正确模块的直接通过分支。只使用内置规则与真实 unittest，不调用模型。
4. 真实模型运行结束后，在交付区或最近运行点击“继续迭代”，填写新增要求。系统继承选定版本的源码与旧测试，创建新运行，保留父记录。
5. 运行时查看当前响应、代码草稿与关键交接；等待状态原位更新。点击“停止运行”保留检查点；中断记录可从失败节点继续。
6. 完成后比较逐轮源码、差异与实际测试，下载报告或完整交付包。选择“仅静态审查”的运行仍会标记未实测。
