# Homework 2 要求对应

依据 Homework 2 的项目目标、技术要求、评分与提交页整理；2026-10-13 核对的备份还包含课程规划附录，附录未新增本次个人作业功能要求。截止时间为 2026-10-25 24:00（即 2026-10-26 00:00，Asia/Shanghai）。本项目选择“编码 → 审查 → 修复”方向。

| 要求 / 评审维度 | 实现与证据 |
| --- | --- |
| 至少两个 Agent 协作 | `CodingAgent`、`ReviewAgent`、`RepairAgent`；缺陷演示实际执行全部三个角色 |
| 完整端到端流程（40%） | 需求输入、模块与测试交付、独立审查、修复、复审、报告；缺陷版失败到修复版八测试通过 |
| 消息与状态管理（30%） | 有序 `code_ready/review_result/repair_ready` 消息；共享产物、节点状态、代码/测试哈希和持久化检查点 |
| 基本顺序执行 | `WorkflowRunner` 根据当前节点显式路由；CLI 与 Web 共用控制器 |
| 条件分支与循环 | 正确模块直接交付，失败模块修复后复审；最多 1–5 轮，预算终止明确记录 |
| 并行执行 | 审查内部 AST 和实际测试检查并行，角色间交接保持有序 |
| 执行日志与追踪 | NDJSON 实时事件、可视化节点、耗时、历史记录、状态 JSON |
| 错误与恢复 | 失败/取消检查点、恢复当前节点、保留已完成产物、API 临时错误有限重试 |
| 可扩展性（20%） | 角色接口、Agent 注册表、JSON 流程定义；测试真正加入并执行观察者节点 |
| 文档（10%） | README、DESIGN、Desgin 入口、Mermaid 流程与架构图、验证记录 |
| 源码仓库 | https://github.com/dankingzzzing/AgentCoder |
| 小于 200 MB 的学号姓名备份包 | `scripts/package_submission.py` 生成 `artifacts/2412190104唐佳杰.zip`，排除真实凭据和内部运行数据 |

本轮新增可视化流程编排：模板、节点交接方向选择、JSON 导入、保存和启动前校验；支持迭代证据回放、完整交付 ZIP 与十场景自动验收。界面采用路由表编辑，没有拖拽。备份包可供用户提交到课程“002Homework2”，本工具没有该课程系统的访问接口。

| 评分维度 | 可直接展示的补强证据 |
| --- | --- |
| 流程完整性 40% | 三类需求都真实运行冻结 unittest；正确代码走直接交付；无效修复、预算终止、恢复均有验收用例；单次交付 ZIP 可重跑 |
| Agent 协作 30% | 每次交接对应消息、源码版本与哈希；修复前后 unified diff；问题 / 实测状态逐轮对比；观察节点不能修改状态副本 |
| 可扩展性 20% | 网页路由编排、保存与校验；增加验收观察节点并实际执行；历史运行保存自己的流程定义 |
| 文档 10% | 更新架构、流程约束、复现命令、验收样例、一分钟视频与答辩路径 |
